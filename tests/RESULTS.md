## 見つかった不具合
1. **聞き取りがスクリプトに引きずられる（主因）**：v1 はスクリプトを見せたまま「何を言ったか」と「各語の判定」を同時に出させていたため、言っていない語・言い間違えた語も「言った」ことにされ、書き起こしもスクリプトの丸写しになっていた（T2・T3・T7）。
2. **完了度が点数に入っていない**：1文で止めても 72 点（T5）。
3. **語の印が別の語に付く**：画面側は `1:30`→2語、`P.M.`→2語、`five-minute`→2語と数え、Gemini は1語と数えるため、その文の以降の印がずれていた（例：`office` の抜けが `our` に、`walk` の抜けが `five-minute` に表示）。100本中 82 文が該当。
4. **48 kHz→16 kHz の変換が線形補間のみ**：8 kHz 以上の成分が折り返して s / sh / th が濁る。12 kHz のテスト音が −2.1 dB で混入（修正後 −56.6 dB）。
5. **録音冒頭の切り詰めの基準がずれる**：録音開始イベントより前の時刻を基準にしていたため、録音の立ち上がりが遅い端末では最初の語を削り得た。0.3 秒の余白を残す方式に変更。
6. 文ごとの聞き比べ（お手本→自分）がカウントダウン分ずれていた。

## 残る限界
文脈から語が明らかな軽い訛り（Sank you→Thank you、rast week→last week など）は、書き起こしの段階で正しい語に聞き取られるため語の印は付かない。発音スコア（T7 は 75）と指導ポイントには反映される。
検証は合成音声によるもので、実際の学習者の録音では数値が変わる。
